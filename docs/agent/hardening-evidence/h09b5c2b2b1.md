## Implementation

- Direct demands carry `receiverSource` separately from ordinary/captured-value `source` and static checker `receiver`.
- `sourceProof` shares immutable alias/union/closed-parameter/ordinary-return traversal and existing limits (depth 128, work 4,096, sources 256). Function and receiver expression/return/active caches are disjoint. A receiver-returning call still resolves callees using function sources.
- Receiver terminals require actual directly named, unwritten, non-generic class declarations outside generic lexical contexts. Every directly named ordinary ancestor is checked too. Constructor expression-returns, even `return this`, make the proof unknown; bare returns and nested callable returns do not imply replacement.
- Constructor aliases, generic/uncertain bases, assertions, dynamic storage/readback, mutable bindings, generic contexts/factories, cycles and exhausted proofs are unknown. Unknown is never an empty set.
- `receiverMayReach` is independent of the static-type-only `mayReceive` cache. Proven exact classes retain their own/ancestor candidates and override-blocking descriptor entries, while excluding unrelated classes and literal/function-as-method candidates. No runtime receiver/capture is substituted.
- The shared declaration-use index now tracks class writes, including bounded outer-expression assignment targets (review C257 below).
