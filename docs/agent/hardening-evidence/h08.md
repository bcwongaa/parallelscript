## The fix

D-187 has the design. In short:

- `pts/lower/yield_expressions.go`: `keepCurrent` keeps every compound target's value before the suspension (it skipped getters and dynamic or union receivers), and `readKeptAndStore` (`lower.go`) uses it instead of calling the getter again; `hoistLogicalAssignment` (with `placeValue` and `storesNullish`) tests a logical assignment's place once and suspends and stores only in the branch that stores; `isSettled` no longer settles postfix `++`/`--`, `in`, or operators converting a non-primitive operand (`isPrimitive` takes unions of primitives); `evaluationOrder` puts an access callee after its object and key, `isSettledCallee` settles methods, functions and the libraries' members, and `keep` keeps any other callee, through `keepCallee` and the new `DynamicMethodOf` for a member found at run time.
- `pts/lower/dynamic.go`: `dynamicMethodCall` calls a kept callee with the new `DynamicCallFound`.
- Runtime: `pts_dynamic_method_of`, `pts_dynamic_call_found` and its spread variant (`dynamic.c`); `pts_builtin_method_has` (`dynamic_methods.c`, `pts_builtin_method_call` split around a table lookup) and `pts_iterator_has_method` (`generator.c`). IR and C emitter: `ir.DynamicMethodOf`, `ir.DynamicCallFound`.
- Tests: the reproducer's five run tests, the unskipped C25 test, the new skipped `run/suspension_spreads_evaluate_first.pts` (H08b; its spread cases moved out of `suspension_operands_evaluate_first.pts`, its expect block Node's output), and two C unit tests in `pts/runtime/tests/dynamic_test.c`.
- **One test line changed:** in `logical_assign_suspends_only_when_storing.pts` the case `local ||= keeps` printed an empty result after `=> `, so Node's line ended in a space, which an `// expect:` block can't hold (`TestRun` failed on that line alone while `TestRunMatchesNode` passed). The case now prints `n 3` as its result. Its RED on the base is unchanged.
