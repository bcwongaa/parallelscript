## The reproducer's link test

The reproducer's `TestEmitCPrintsTheCThatBuildLinks` asks that a build fall back past a link failure and that emit-c print the C it then links. D-199 keeps a link failure from falling back instead (`TestABuildWhoseCDoesntLinkDoesntFallBack`): emit-c would have to link at the build's optimisation level to agree (dead code at -O2 decides an undefined reference), a full release build (the reproducer's timings: 1.3–28 s against 0.15–2 s for the syntax check), and no natural case is known (its pool scan and smoke runs with clang: none).
