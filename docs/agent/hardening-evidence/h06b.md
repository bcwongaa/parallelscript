## Commands

- The nine RED tests and the new ones, against any CLI: `python3 -I tools/runexpect.py --pts <cli> --home <PTS_HOME> [--threads n] <files>` (in the parent archive). It compares stdout with the expect block and doesn't read `// exit:` or `// stderr:` directives.
- The H06 matrix: `tar xzf docs/agent/hardening-evidence/h06-reproducer-probes.tar.gz -C <tree>`, then:
  ```sh
  python3 -I <tree>/h06-probes/gen.py --out <dir> --seed 0
  PTS_HOME=<tree> python3 -I <tree>/h06-probes/run_matrix.py --dir <dir> --out <json> --scratch <work> --jobs 2
  python3 -I tools/families_run.py <tree>/h06-probes <json>
  python3 -I tools/breakdown.py <tree>/h06-probes <json> results/matrix-base.json.gz
  ```
  `run_matrix.py` needs `<tree>/pts-bin/pts`, and the last two tools are in the reproducer's archive.
- Benchmarks: build each `bench/*.pts` with both CLIs, then `PTS_THREADS=1 valgrind --tool=callgrind --callgrind-out-file=<f> ./<binary>`. `tools/cgdiff.py base.cg new.cg` lists the functions whose self counts changed most.
