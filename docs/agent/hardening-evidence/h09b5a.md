## Costs

- Polymorphic recursion now compiles 64 instances deep: about 80 lines of C per level of each recursive demand (`generic_polymorphic_recursion_dispatched`: 5,232 lines, 1.5 s; base: PTS9001). The depth's cost is linear (`depth/`: the first trials test at depth 16, 32 and 64: 17k, 33k and 66k lines, 4.4, 9.2 and 21 s); the test was split, since its two recursive values of one erased type pair with each other's demands (C172's growth): 16 s together, 1.8 and 3.9 s apart.
- Branching recursion stops at its root's budget: review round 1's `branching_dispatched` compiles in 8.9 s (258 MB) and prints Node's 6 (base PTS9001); `branching_direct` 1.0 s and prints Node's 5 (base PTS1001); `product_blowup` 0.3 s (base 8.3 s, the fix commit 86 s); round 3's `fanout2_9` 4.0 s (round 2's code 26 s, 1.1 GB); round 4's `branch_roots_40` stops at the function's total in 0.3 s (round 3's code 24.7 s) and `giveback_classes` at a class's in 1.7 s (round 3's code: still compiling at 900 s); round 5's `giveback_work` 1.4 s (round 4's code 150 s).
- A generic class's 33 instances × 32 instances of its generic method (round 2's `c_method_instances_per_declaration`, no recursion): compiles in 35 s, 1.0 GB, and prints Node's 33264 (base 75 s under load).

## Known gaps
