## Review round 1 (NOT READY: 1 High, 1 Medium, 4 Low, 2 Notes; [report](h11b-review.md#round-1-snapshot-2--813a156cc-archive), [archive](h11b-review1-probes.tar.gz))
Reviewed snapshot 2 (`813a156cc`). The reviewer reproduced D-221's costs and the matrices' gains, found no shape mismatch from the kept callback defaults and no unchecked write into a loose local's union.
- **R1-F1 (High, regression for loose locals):** `looseRead` read a loose local narrowed to a primitive or tuple member of its union (a lying type predicate, a narrowing a closure's assignment made stale) with the undefined test alone, an unchecked cast: SIGSEGV where the base threw TypeError (`m12`, `m13`, `m20`, `m26`; parent: all four crash on snapshot 2, TypeError on the base). Fixed: only a narrowing to a class of the union (`isCheckedClass`: D-067's instance check follows) takes the undefined test; anything else is checked as a dynamic value's is, as on the base. With it D-140's check for stale narrowings now covers tuples and object types (`narrowedUnionRead`), which fixes the pre-existing crashes `m21`, `m23` (a stale tuple narrowing of an ordinary local and of a `for…of` variable). Test `run/loose_locals_narrowed_checked.pts` (no-diff; crashes on the base and snapshot 2).
- **R1-F2 (Medium):** `+` with a union, `any` or type-parameter side concatenated a missing value (`undefined5`, Node NaN). Fixed: the missing side is read as any value only where every value of the other side is a string or an object (`concatenatesAsString`). Test `concatenation_missing_values.pts` extended.
- **R1-F3 (Low, pre-existing):** `case undefined` over a number tag, and a loose number tag's numeric cases, were PTS1001. Fixed: such cases compare what they hold strictly (`caseMatch`). A `void` tag keeps PTS1001 (an intermediate fix reached the C compiler with it, found by the parent's replay of `w01`). Test `switch_case_undefined.pts` extended.
- **R1-F4 (Low, pre-existing):** a default of an `unknown`, `any` or `T | undefined` parameter never applied to an undefined argument (callbacks at holes, `Array.from({ length }, (v = 5) => v)`, ordinary calls). Fixed: `maybeUndefined` (the parameter's type no longer decides; `takesUnion` removed), and `callbackArguments` leaves a constant undefined out. Test `run/defaults_take_undefined_arguments.pts`.
- **R1-F5 (Low):** `s += "x"` and `void s` of a loose local threw TypeError (Node `undefinedx`, `undefined`). Fixed. Test `run/loose_locals_concatenation.pts`.
- **R1-F6 (Low):** a parenthesized `Array.from` mapper lost its default. Fixed: `closureSignature` looks through parentheses. In `defaults_take_undefined_arguments.pts`.
- **R1-F7 (Note, cost):** a `string[]` callback method with a defaulted element parameter, 1.10×; recorded in D-221's costs.
- **R1-F8 (Note, pre-existing):** `I & string` from a lying predicate on an interface: PTS9001 → C322, H29.
- The reviewer's `m07` and `m15` (a lying predicate on an ordinary local's primitive union) crash on the base, snapshot 2 and the fix alike: pre-existing, high → C321, H20 (and REVIEW_LATER), not fixed here: a check on every narrowed read to a primitive would cost sound narrowings.
