## Implementation and conservative boundaries

- `forwarder.source` identifies its exact creation AST, not its captured value. `boundMethod` sets it only after actually creating a forwarder; `addForwarder` registers it only within its existing AllInstances/non-erased gate. No property-read guesses from static receiver types.
- `wrapper_sources.go` accepts actual property-read creation sites; zero-bound-argument bind uses the whole call, not the `.bind` member. The bounded ancestor walk excludes generic classes and syntactic or checker-contextual generic functions, including nested code. One AST token represents **all** its runtime receivers, lexical captures and enclosing instances.
- `value_flow.go` recognizes registered wrapper sites inside existing proof limits. `sourceMayReach` filters only ordinary value demands with proven sources. Named-method demands, unknown-origin forwarders and unknown source proofs stay conservative. A cached unknown remains safe after later registration; it may lose precision, never becomes empty.
- `valueForward` carries the bind target or method-field initializer/shorthand expression into its inner synthetic demand. `instantiatingAdapterSkipping` carries the normalized adapted expression, including explicit-instantiation operands. Never substitute the outer caller's source for the captured expression.
- Existing depth 128, work 4,096 and union 256 bounds remain. Unknown/any/container readback, mutable/escaped consumers, generic contexts and exhausted proofs retain compatible instances. Method dispatch, closure capture sharing, compatibility, trial/fallback ordering, containing-code caps and checked-any conversions are unchanged. Compatible-candidate enumeration itself is **not** claimed eliminated.
