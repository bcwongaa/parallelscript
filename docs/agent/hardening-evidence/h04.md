## Causes and fix

- **No containment.** Nothing recovered a panic of the compiler's: the CLI printed Go's trace and exited with 2 (the usage error's code), `pts test`'s concurrent builds and the in-process test harness died with one program's panic, and clang's rejection of the generated C was printed as a toolchain failure with the whole command line. The fix is D-179's containment (`diagnostic.Locate`/`Contain`, positions tracked by each phase, `generatedCFailure`, exit code 3, `PTS_DEBUG=1`).
- **C26 and its family (the reproducer's B):** the value of `=` (and `op=`) on a dynamic or union-typed place had the store's IR type, `Value` or the union, where tsc types the expression as the right side's; code using it dispatched on tsc's type. Fix: `assignmentValue` narrows it as a read of the place is, arrays and maps by H02's `assignedValue`.
- **C39 and C66:** `narrowedValue` converted a dynamic value narrowed to a class, primitive or `any[]` only, so a tuple, typed array, record, map or set stayed a `pts_value` that typed code took for the narrowed type. Fix (after review round 1): typed values held dynamically are converted with a check; values stored dynamic stay dynamic and their members go the dynamic way (`isNarrowedDynamic`).
- **C34:** `accessorFields` looked fields up by tsc's internal symbol name (`__@iterator@NN`) while the shape names the field `@@iterator`, and the object literal's lowering skipped computed-name accessors (`literalMemberName`). The runtime read `@@iterator` up to three times through `any` (C68; `pts_iterator_method`).
- **C50:** `spreadNames` returned nil for an object without properties, which its callers took for a reported failure, so the declaration was dropped without a diagnostic; `destructure` had no net for that (`unexplained`).
- **C63:** `restProperties` and `assignParts` took a `SpreadAssignment`'s `Name()` (nil). **C64:** a type assertion on a rest parameter's type, which may be a tuple (`methodParamTypes`). **C65 and review finding 4:** `accessorsKey` didn't tell a getter alone from a getter and setter, and `copyShape` gave an interface an accessor literal's shape for its copies.
