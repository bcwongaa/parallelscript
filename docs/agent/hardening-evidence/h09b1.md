## The fix

D-191 has the design. In short:

- `pts/lower/instances.go`: `demand.name`, `.shape`, `.receiver`; `namedInstanceCall` (one lowering of the arguments, to the erased parameter types; `argumentNodes`, `passedAsIs`, `passesAsIs`, `takesUnverifiedObjects`, `verifiesObjects`; a dynamic result for a union's call); `specialize` pairs demands by name with `genericMethodList` and erased values; `specializeMethod` for any class's method of the name that may receive the call (`mayReceive`, `receiving`, `classType`), type arguments inferred in context for dispatched demands too; `specializeValue` with `reaches` (literals' methods of the name whose literal may be the receiver).
- `pts/lower/methods.go`: `objectMethod` makes a generic literal method a `genericFunc` (`genericFunc.field` in `generics.go`). `pts/lower/objects.go`: `interfaceMethodCall`'s shape and interface branches; `pts/lower/union_objects.go`: `unionMethodCall`.
- `pts/lower/lower.go`: `ValueInstances`, `Fallbacks`, `lowerer.receives`; `closures.go`: H09a's instances under `ValueInstances` too. `pts/driver/driver.go`: the fallbacks in turn.
- `pts/ir/ir.go`, `print.go`: `InstanceCall.Dynamic`. `pts/cgen/classes.go`: `instanceCall` (`pts_method_instance_find` through a site; named entries take the closure, then the object; the array-argument guard; a dynamic result boxed), `instanceTable` (the convention).
- `pts/runtime/src/object.c`, `include/pts.h`: `pts_method_instance_find`.
- Tests: `run/generic_interface_methods.pts`, `generic_object_literal_methods.pts` and `generic_method_any_boundaries.pts` (the reproducer's), `generic_interface_methods_threads.pts`, `generic_interface_methods_arguments.pts`, `generic_interface_methods_overrides.pts`, `generic_union_method_results.pts`, `generic_method_erased_objects.pts`, the skipped `generic_method_object_arguments.pts` (H09b2); an interface case appended to the no-diff `generic_instances_that_dont_lower.pts`; `generic_method_factories.pts`'s skip line names H09b3; `lower_test.go`'s `TestInterfaceCallsFindTheInstancesOfClassesAndObjectLiteralsMethodsByName`; `driver_test.go`'s `TestInterfaceCallsMakeNoDemandsInTheFallbackBuilds` and `TestABuildThatOnlyItsDemandsByNameStopKeepsTheGenericArrowsInstances`; `object_test.c`'s `method_instances_are_found_in_classes_then_in_a_literals_method_closure`.
