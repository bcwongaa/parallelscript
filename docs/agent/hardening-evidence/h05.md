### What changed (D-181)

The leaf check now follows where a callback's values are made (`keepsLeavesOf`). It reads through maps, `Array.from`, same-element methods, `concat`, `Array.of`, nested `flatMap`s, a literal's `flat()` and consts the callback makes at each call. A const of the enclosing code is a kept array at each call (round 6). Nested tuple literals are checked by position, so spreads, `as const` and `satisfies` are covered (round 6). Tuples a cast or an annotation makes are reported where an array goes (round 7). Iterable spreads are checked, and a shorthand property, its default or an export is a use of its const (rounds 8 and 9). Hash maps, maps and sets of other types are reported, also as union members, and so is an object where a hash map goes (rounds 10 and 11). A hash-map literal is checked by the type it is made as (round 11). The runtime converts an array or a tuple shorter by optional elements to a tuple type (`convert.c`, round 6, finding 5). Rounds 7–10 approved copies of fresh object literals into interfaces property by property; each round found a copy the interface's shape doesn't survive, so that approval was reverted to the commit's type check (time-boxed, D-181).
