## Causes and fix

The reproducer's root causes, verified in code at the base (its report's "Root causes"): no `PTS_KIND_GENERATOR` case in `pts_builtin_method_call` (C28); `iteratorMethodCall` building a D-109 shape at the call from `done` and `IteratorValue` (C30); `delegation` yielding the inner value (C32); the object iterator's step reading every non-done result's `value` (C33) and `pts_iterator_close` resuming through the same step (C41); unchecked casts of D-109 shapes out of their union, reached by `as` and by conversions from `any` (C35); `copy_object` reading getters for conversions from `any` (C42). The fix is D-178: result types hold whatever object an iterator handed back, read by field on the runtime's shapes and by name on anything else; see SPEC §9.122 for where each part lives.
