## The fix

See D-185. `pts/lib/internal/abort.pts`: a lock per `EventTarget` (`#lock`, pts:sync's futex intrinsics) over the listener list and an AbortSignal's state, held only around plain reads and writes; `AbortSignal.any` as the DOM standard's dependent signal (`#sources`, `#dependents`, `#follow`, `#settle`); `signalAbort` as "signal abort"; `addEventListener`'s `{ signal }` in Node's order (its remover first, appended with no duplicate scan, used up by a flag, resisting `stopImmediatePropagation`) with a re-check (`abortedNow`); `onabort`'s first handler claimed under the lock; a frozen signal's abort throws before anything changes (`Object.isFrozen`), and one frozen meanwhile releases the lock and is put back. `pts/lib/http.pts`: `OWN_SIGNAL_LOCK` for `Request`'s lazily made signal and the server's disconnect; `exchange` re-checks the signal after adding its listener, typed `EventListener`.
