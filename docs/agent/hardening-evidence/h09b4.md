- `pts/lower/dead_code.go` (new): dead reads (`deadRead`, `evaluatedFirst`, `isDeadRead`, `takesAnyValueAsIs`), the test for every type argument of the instance's IR types (`deadTest`, `widestOfIRType`, `literalFree`), types no value has (`uninhabited`, `disjoint`, `valueKind`), and the traps (`trap`, `statementOrTrap`, `statementList`, `deadOperand`).
