## The fix

D-195 has the design. In short:

- `pts/lower/dead_code.go` (new): dead reads (`deadRead`, `evaluatedFirst`, `isDeadRead` with `testedType` and `mentionsParameters`, `takesAnyValueAsIs`), the test for every type argument of the instance's IR types (`deadTest`, `widestOfIRType`, `isDynamicIRType`, `literalFree`), types no value has (`uninhabited`, `disjoint`, `valueKind`), the constants (`isPrimitive`, `neverStrictlyEqual`), and the traps (`trap`, `statementOrTrap`, `statementList`, `uninitialized`, `deadOperand`).
- `pts/lower/lower.go`: statements and switch clauses through `statementList`; `sameType`'s dead branches; `logicalWithDeadRight`; strict equality across primitive kinds; never element reads; `resultType` (`returnsNeverValue`). `unions.go`: `??`'s dead right operand. `classes.go`: `instanceof` on a primitive. `closures.go`: arrow expression bodies. `generics.go`: `narrowedInstance` in `instantiate`. `instances.go`: `narrowsAway` removed.
- Upstream: `internal/checker/pts.go`'s `PtsIntersectionType` and `PtsReducedType` ([FORK.md](../../FORK.md)); `go test ./internal/checker/...` passes.
- Tests: the reproducer's eight instance tests (`generic_narrowed_dead_branches` without its discriminant lines, `_dead_regions`, `_dead_branch_direct_calls`, `_dead_branch_values`, `_intersections`, `generic_narrowed_live_controls` without its plain functions, `generic_never_type_arguments`, `generic_never_results`) and its guard (`narrowed_never_branches_that_run`); the parent's `generic_dead_branches_shared_instances`, `generic_dead_branch_lies` (no-diff); after the review rounds `generic_narrowed_stale_narrowings`, `generic_dead_tail_bindings`, `generic_dead_reads_any_value`, `generic_narrowed_library_types`, `generic_narrowed_dead_spreads`, `generic_instances_dead_branches` (renamed from `generic_instances_that_dont_lower`, now against Node), `generic_factories_fallbacks` (now against Node), `generic_never_value_call` (unskipped, extended); skipped for H09b4b: `narrowed_dead_branches_plain`, `branded_primitives`, `in_narrowing_absent_member`, `generic_narrowed_constraint_discriminants`; `lower_test.go`'s new test, and three tests whose failing instance came from a dead narrowed branch now build it from `==` between a string and a number (`TestAGenericArrowsInstanceThatDoesntLowerIsDroppedWithWhatItMade`, `driver_test.go`'s two fallback tests).
