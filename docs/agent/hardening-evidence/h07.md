## The fix

`pts/lib/internal/abort.pts`: the module-level `let constructing` and `newSignal()` are gone. `const SIGNAL_KEY = {}` is the module's key, and `AbortSignal`'s constructor takes `key?: unknown` and throws `TypeError: Illegal constructor` unless it gets the key. `AbortSignal.abort`, `timeout`, `any` and `AbortController` pass it (D-184).

- The parent's first version used a private class (`class SignalKey { readonly #brand = true }`). Through `any` it threw `TypeError: Expected SignalKey, got Object` where Node says `Illegal constructor` (`edge/edge.pts`), so the key's type became `unknown`.
- Parent checks against Node (`edge/edge.pts`, `edge/ident.pts`): `new AbortSignal()`, `(undefined)`, `({})`, `(1)`, `(null)`, an `any` object, an `any` undefined and a subclass all throw `TypeError: Illegal constructor`. `instanceof`, `console.log` of a signal and the statics are unchanged, and empty object literals are distinct objects.
- Programs can't import `pts:internal/abort` (PTS1002, `edge/imp.pts`), and `SIGNAL_KEY` isn't exported.
