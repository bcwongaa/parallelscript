## Implementation
The parent merged its own fixes (C12's `defaultOfUndefined`, C307's `defaultPastTheEnd` and rest copy, C306's loose parameters, C326/C327's `writesMissing`) with the reproducer's prototype (`patternTargetType`, `patternDefault`'s tuple literals, RC3b, RC6), then fixed N1 (generators bind parameters at the call: `ir.Func.Prologue`), N3 and N4 (`patternDefault`), kept the parameter's union only where the default's type holds undefined itself (the prototype also kept it for `any`/`unknown` defaults, whose undefined tsc removes in the body), and kept undefined in the semantic pass's `parameterNumeric`. See D-222 and SPEC §9.147. A first form of `writesMissing` made every variable loose that was ever written an element read or a loose local; the emit-c sweep showed three corpus programs' reads after a write tsc types `T | undefined` (`c ? xs[i] : undefined`) newly checked, so the rule takes writes that tsc types without undefined only, and not `any` variables (tsc keeps `any` at an assignment).
