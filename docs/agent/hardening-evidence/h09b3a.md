## The fix

D-193 has the design. In short:

- `internal/checker/pts.go`: `PtsWithoutCallChain`, `PtsIsOuterCallChain` (listed in `docs/FORK.md`).
- `pts/lower/instances.go`: `demandAt` strips the call-chain flags (`demand.chained`, `fromErasedFor`) and accepts rest parameters (`isErasedRest`, not in `DeclaredInstances`); `erasedArguments` copies the call's rest array for the erased copy; `namedInstanceCall` lowers its arguments once (`argumentList`) and `passedAsIs` builds the instance's rest array (`restAsIs`); `passesAsIs` takes an object of a union member as it is (`providedMember`, `leavesOut`, `verifiesObjects`); `holdsUnverified` has a `Rest` case.
- `pts/lower/element_calls.go` (new): `constantKeyCall`, `constantKey`, `keyValue`, `isLiteralKey`, `calleeName`, `dottedCall`, `withKeyRead`, `readsSafely`, `isGenericMethodSymbol`; called from `call` (`lower.go`); `interfaceMethodCall` (`objects.go`) and `unionMethodCall` (`union_objects.go`) take the name from `calleeName`.
- `pts/lower/chains.go`: `optionalChain` keeps the object of a method's optional call (`calledMethodReceiver`, `mayHaveEffect`, `optionalChainFrom`). `pts/lower/generic_classes.go`: `receiverClass` takes a chain link's non-optional type. `pts/lower/generics.go`: `resultTypeArguments` checks rest arguments. `pts/lower/lower.go`: `argumentList` (from `typedArguments`).
- Tests: new `run/generic_optional_chain_calls.pts`, `generic_optional_chain_inner_calls.pts`, `optional_method_calls_evaluate_receiver_once.pts` (with a module), `generic_element_access_calls.pts`, `generic_element_access_key_reads.pts`, `generic_union_literal_arguments.pts`, `generic_rest_parameter_calls.pts`, `generic_rest_spread_arguments.pts`, `generic_rest_result_contexts.pts` (against Node), `generic_call_forms_any_boundaries.pts` (no-diff); `generic_method_literal_arguments.pts` unskipped; the skipped `generic_method_factories.pts` now names H09b3b; H09b2's `erased_objects_typed_reads`, `erased_objects_union_routes`, `erased_objects_typed_writes`, `erased_objects_integer_reads`, `erased_objects_par`, `erased_objects_closure_calls`, `maps_sets_convert_by_copy`, `union_conversion_member_choice` and `generic_method_erased_objects` get their erased copies' objects from an `any` argument (D-191) or a call through `any` (D-078), since their element-access and `?.` producers now find instances (round 1's F4; gdb hit counts in `gdb/hits_after.txt`: every erased copy runs again); `lower_test.go`'s `TestElementAccessAndOptionalCallsOfGenericMethodsFindTheirInstances`.
- No runtime or C emitter change. Upstream: `internal/checker/pts.go` only.
