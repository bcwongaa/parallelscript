## The fix

D-188 has the design. In short:

- `pts/lower/yield_expressions.go`: `keep` keeps a spread as what it spreads then. `keepSpread` (arguments, `new`, array literals) keeps `spreadSnapshot` of the spread's value, or for `a.keys()`, `a.values()` and `a.entries()` of an array, tuple, typed array, map or set, of their receiver (`iterationReceiver`): an array's copy (`ArraySlice`, holes kept), a tuple's (optional elements raw), a typed array's (`pts_typed_array_slice`), a map's or set's (`NewMap{From}`), a union's, a dynamic value's or an object's items (`ValueToArray`), a string or a literal's new array as it is. `keepObjectSpread` copies a hash-map object and reads a class instance's, an object's or an interface's properties into an object of a values-only shape (`propertiesCopy`, `valuesShape`), recording their names and the source's type (`keptSpreads`, read by `copiedNames`). `isSettled` settles a `SpreadElement` only for a settled string or array literal, a `SpreadAssignment` never; `evaluationOrder` lists the `SpreadAssignment`.
- `pts/lower/objects.go`, `records.go`: `spreadObjectLiteral` and `spreadIntoRecord` take the names (and the type their diagnostics name, `spreadProperty.of`) from `copiedNames`.
- `pts/lower/lower.go`: the `keptSpreads` map.
- Tests: the unskipped `run/suspension_spreads_evaluate_first.pts` (its header updated); the reproducer's `suspension_spread_arguments_evaluate_first`, `suspension_spread_iterables_evaluate_first`, `suspension_object_spreads_evaluate_first`, `suspension_spreads_in_other_forms`; the skipped `spread_elements_read_before_later_arguments` (H08c, C152); review round 1's `suspension_spread_copies` and `errors/object_spread_suspension`.
- No runtime or C emitter change; no upstream package touched.
