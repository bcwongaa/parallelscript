## The fix

D-192 has the design. In short:

- `pts/runtime/src/object.c`: `reads_as_is`, `read_converted`, `optional_converted` (typed reads verify declared types, converting as they are or throwing); writes convert across kinds (`pts_field_set_slow`, `pts_property_find_slow`).
- `pts/runtime/src/convert.c`: `pts_value_try_convert_as_is` (closures adapted); the union case (`union_member_as_is`, `union_member_copy`, `object_readable`, `is_class_instance`, `covering` with `union_properties`/`properties_of`, `covering_record`, `covering_cached` with `readable_members`, `resembles`); `implies` with union targets; `pts_check_implies`' per-thread cache; `source_property` keeps absent properties; copies of frozen values are frozen; `convert_map`. `pts/runtime/include/pts.h`: the declaration and the site comment.
- `pts/lower/lower.go`, `dynamic.go`: dynamic values into union-typed places checked unless `trustsDynamic`; `prepareCheckedUnion` (`copyShapesOptional`, `makeCopyShape`). `pts/lower/unions.go`: `leavesOut`, `propertyType`, `holdsDynamicValues`. `pts/lower/instances.go`: `verifiesObjects` is `holdsUnverified`.
- Tests: new `run/erased_objects_typed_reads.pts`, `erased_objects_closure_calls.pts`, `erased_objects_union_routes.pts`, `erased_objects_typed_writes.pts`, `typed_any_fields_to_unions.pts`, `erased_objects_par.pts`, `erased_objects_lies.pts` (the reproducer's seven, adjusted), `erased_objects_integer_reads.pts`, `narrowed_unknown_into_union.pts`, `union_conversion_member_choice.pts`, `union_conversion_keeps_typed_objects.pts`, `union_member_covariant_arrays.pts`, `maps_sets_convert_by_copy.pts`, `generic_method_odd_element_arguments.pts`, skipped `generic_method_literal_arguments.pts` (C188) and `generic_never_value_call.pts` (C194); `generic_method_object_arguments.pts` unskipped (its object-literal line moved to the skipped test, a variable form added); `generic_method_erased_objects.pts`'s lie moved to `erased_objects_lies.pts`, where it throws TypeError (D-L09) as typed code does; C unit tests in `convert_test.c` and `object_test.c`.
- No upstream package touched.
